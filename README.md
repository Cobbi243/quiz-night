# Quiz Night — Своя Гра

Стрімерський квіз у форматі Jeopardy. 6×5 дошка, баззер, ведучий судить.

## Швидкий старт (15 хвилин)

### Крок 1 · Firebase проєкт (5 хв)

1. Зайди на **https://console.firebase.google.com/**
2. Натисни **Add project** (Створити проєкт):
   - Назва: `quiz-night` (або будь-яка)
   - Google Analytics — можна вимкнути, не потрібно
3. Створ. Зачекай ~30 сек.

### Крок 2 · Realtime Database (2 хв)

1. У меню зліва: **Build → Realtime Database**
2. **Create Database**:
   - Регіон: оберіть найближчий (Europe — Belgium / Frankfurt)
   - Режим: **Start in test mode** (відкритий доступ на 30 днів — норм для початку)
3. БД створена. Збережи URL що показався (виглядає як `https://xxx-default-rtdb.europe-west1.firebasedatabase.app/`)

### Крок 3 · Anonymous Auth (1 хв)

1. У меню: **Build → Authentication**
2. **Get started**
3. Вкладка **Sign-in method**
4. Знайди **Anonymous** → **Enable** → Save

### Крок 4 · Отримати config (2 хв)

1. ⚙️ біля Project Overview → **Project settings**
2. Прокрути вниз до **Your apps**
3. Натисни значок **`</>`** (Web)
4. App nickname: `quiz` → **Register app**
5. Скопіюй об'єкт `firebaseConfig` — він виглядає так:

```js
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "quiz-night-xxx.firebaseapp.com",
  databaseURL: "https://quiz-night-xxx-default-rtdb.firebaseio.com",
  projectId: "quiz-night-xxx",
  storageBucket: "quiz-night-xxx.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc..."
};
```

⚠️ **Перевір що є `databaseURL`!** Якщо немає — додай вручну, скопіювавши URL з кроку 2.

### Крок 5 · Вставити у config.js (1 хв)

Відкрий `config.js` у текстовому редакторі (Notepad, VS Code, що завгодно).
Заміни значення на свої. Файл має виглядати так:

```js
window.QUIZ_CONFIG = {
  firebase: {
    apiKey: "AIzaSy...",   // твої справжні значення
    authDomain: "quiz-night-xxx.firebaseapp.com",
    databaseURL: "https://quiz-night-xxx-default-rtdb.firebaseio.com",
    projectId: "quiz-night-xxx",
    storageBucket: "quiz-night-xxx.appspot.com",
    messagingSenderId: "123456789",
    appId: "1:123456789:web:abc..."
  },
  anthropicApiKey: ""  // залиш порожнім — AI-генерацію включи пізніше
};
```

### Крок 6 · Деплой (3 хв)

**Найпростіший варіант — Netlify Drop:**

1. Зайди на **https://app.netlify.com/drop**
2. Перетягни папку з файлами (index.html, app.js, config.js, README.md)
3. Готово! Ти отримаєш URL типу `https://amazing-quiz-abc123.netlify.app/`
4. Це і є посилання на твій сайт. Ділись з друзями.

**Альтернативи:**
- **GitHub Pages**: створи репозиторій, залий файли, увімкни Pages у Settings
- **Vercel**: `vercel deploy` через CLI або drag-and-drop
- **Власний сервер**: просто завантаж файли у будь-яку папку, віддавай через nginx/Apache

### Крок 7 · Безпека (важливо!)

Test mode у Realtime Database діє **30 днів**, після чого БД буде заблокована. Щоб гра працювала довше:

1. Realtime Database → **Rules**
2. Заміни на:

```json
{
  "rules": {
    "rooms": {
      "$code": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    },
    "users": {
      "$uid": {
        ".read": "$uid === auth.uid",
        ".write": "$uid === auth.uid"
      }
    }
  }
}
```

3. Publish.

Це обмежує доступ — тільки авторизовані юзери (анонімна авторизація проходить автоматично) можуть писати в БД, і кожен користувач має доступ лише до своїх паків.

## AI-генерація питань (опційно)

Якщо хочеш генерувати паки через Claude:

1. Зареєструйся на **https://console.anthropic.com/**
2. Купи кредитів (мінімум $5)
3. **API keys** → **Create key** → скопіюй
4. У `config.js` встав ключ:
   ```js
   anthropicApiKey: "sk-ant-api03-..."
   ```
5. Передеплой (просто перетягни папку в Netlify Drop ще раз або зроби push в Git)

⚠️ **Увага:** ключ буде видно у фронтенд-коді. Не використовуй цей варіант якщо сайт публічний — будь-хто зможе підглянути ключ і витратити твої кредити. Для публічного варіанту треба робити бекенд-проксі (Netlify Functions, Vercel Edge, тощо).

## Формат файлу для імпорту питань

Створи `.txt` (або `.docx`) файл такого вигляду:

```
# Кіно
200 | У якій країні зняли «Паразити»? | Південна Корея
400 | Хто зіграв Нео в трилогії «Матриця»? | Кіану Рівз
600 | Скільки фільмів у трилогії ВП? | 3
800 | Режисер «Бійцівського клубу»? | Девід Фінчер
1000 | Який фільм отримав «Оскар» 2020? | Паразити

# Історія
200 | ... | ...
400 | ... | ...
...
```

Правила:
- Категорія починається з `#` або `КАТЕГОРІЯ:` на початку рядка
- Питання: `вартість | текст питання | відповідь`
- Розділювач — символ `|` (з пробілами або без)
- 6 категорій × 5 питань (200/400/600/800/1000)

**Картинки у .docx:** вставляй картинку прямо в той самий абзац що й питання — вона автоматично прив'яжеться до того питання. (У `.txt` картинок немає, лише у `.docx`.)

## Як грати

1. **Ведучий** натискає «Створити кімнату», вводить нік → отримує 4-літерний код.
2. **Гравці** заходять на сайт, тиснуть «Долучитися», вводять код і нік.
3. Ведучий натискає «Налаштувати гру» → вибирає **скільки раундів** (1, 2 або 3).
4. Для кожного раунду ведучий обирає звідки взяти питання (готовий пак / AI / файл / збережений / вручну) → «Стартанути».
5. На дошці 6 категорій × 5 питань. Поточний гравець (підсвічується золотим) обирає клітинку.
6. Питання відкривається. Ведучий читає вголос → натискає «Відкрити баззер».
7. Гравці бачать червону кнопку **«НАТИСНИ ЩОБ ВІДПОВІСТИ»** — перший хто натиснув, відповідає вголос.
8. Ведучий тисне «**Правильно (+N)**» або «**Неправильно (−N)**».
9. При неправильній — інші гравці можуть перехопити.
10. Хто відповів правильно — бере наступне питання.
11. Коли всі 30 клітинок зіграні → екран «Раунд завершено». Бали від попереднього раунду переносяться.
12. У наступному раунді **бали ×2 / ×3** (200/400/600/800/1000 стають 400/800/1200/1600/2000 у 2 раунді, тощо).
13. Після останнього раунду — **фінальний раунд**:
    - Ведучий вписує категорію, питання і правильну відповідь
    - Кожен гравець бачить категорію і ставить кількість балів (0 — до свого поточного рахунку)
    - Потім гравець бачить питання і вписує відповідь у поле
    - Ведучий бачить усі відповіді одночасно і марикірує кожного ✓ або ✗
    - Правильно → +ставка, неправильно → −ставка
14. Фінальна таблиця з переможцем.

## Поширені проблеми

**«Firebase не налаштовано»** — config.js не відредаговано або значення з помилкою. Перевір що apiKey не містить `replace_me`.

**Не вдалось підключитися до Firebase** — переконайся що:
- Realtime Database створено (НЕ Firestore!)
- Anonymous Auth увімкнено
- `databaseURL` у config.js правильний (з протоколом `https://`)

**Гравець заходить — а в лобі його немає** — перевір що Anonymous Auth увімкнено в Firebase Console. Без неї підключення не пройде.

**Не можу залити .docx** — переконайся що файл саме .docx (новий формат Word), а не .doc (старий). Конвертуй через Word/Google Docs якщо треба.
